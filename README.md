# NextWork Projects

A collection of hands-on AWS projects completed through [NextWork](https://nextwork.ai/) as part of my journey towards becoming an AWS Cloud Engineer.

## About This Repository

This repository documents the AWS projects I complete while learning through NextWork's guided tutorials. Each project gives me an opportunity to practise working with AWS services, understand cloud concepts, and gain practical experience.

My goal is to keep my work organised, document what I learn, and have a record of my progress that I can revisit in the future.

## What's Inside?

Each project has its own folder containing relevant documentation and supporting materials, such as:

- Project objectives and implementation steps
- AWS services and technologies used
- Screenshots and architecture diagrams
- Key concepts and lessons learned
- Notes on challenges and troubleshooting

The contents of each folder may vary depending on the project.

## Technologies

The technologies covered in this repository may include:

- Amazon EC2
- Amazon S3
- AWS IAM
- Amazon VPC
- AWS Lambda
- Amazon RDS and DynamoDB
- Other AWS services and cloud technologies

## Learning Approach

These are guided learning projects completed through NextWork. I use them to strengthen my understanding of AWS, practise implementing cloud solutions, and build confidence working with cloud infrastructure.

As I progress, I aim to revisit what I've built, experiment with different configurations, and apply what I've learned to projects of my own.
